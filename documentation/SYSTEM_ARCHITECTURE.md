# System Architecture & Documentation

## Overview
The **Student Registration System** is built for the **College of Information Technology** to modernize and digitize the student enrollment process.

```
                  +-----------------------------------+
                  |           Client Browser          |
                  +-----------------+-----------------+
                                    |
                            HTTP GET / POST
                                    |
                                    v
                  +-----------------+-----------------+
                  |       Laravel Routing (web.php)   |
                  +-----------------+-----------------+
                                    |
                                    v
                  +-----------------+-----------------+
                  |       StudentController           |
                  |  - index()   - store()            |
                  |  - create()  - show()             |
                  +--------+-----------------+--------+
                           |                 |
                Validation & Storage   Eloquent ORM
                           |                 |
                           v                 v
            +--------------+---+     +-------+-------+
            | Laravel Storage  |     |  MySQL DB     |
            | (public/students)|     |  (`students`) |
            +------------------+     +---------------+
```

---

## Component Breakdown

### 1. Controllers (`app/Http/Controllers/StudentController.php`)
- **`index(Request $request)`**: Fetches paginated student records with query filters (`search`, `program`, `year_level`) and calculates enrollment statistics.
- **`create()`**: Delivers the registration form view populated with system program and year level constants.
- **`store(Request $request)`**: Validates all incoming data, uploads and stores profile images to public disk, persists student records to MySQL, and redirects with flash message.
- **`show(Student $student)`**: Renders the individual student digital ID card and details view.

### 2. Models & Database Layer (`app/Models/Student.php`)
- Eloquent Model representing the `students` table.
- Encapsulates:
  - `$fillable` array for mass assignment security.
  - Accessors: `full_name`, `formal_name`, `profile_picture_url`, `formatted_dob`, `age`.
  - Date casting on `date_of_birth`.

### 3. Views (`resources/views/`)
- `layouts/app.blade.php`: Master template with Tailwind CSS, Font Awesome icons, navigation header, and dismissible flash messages.
- `students/create.blade.php`: Responsive registration form with logical section groupings, client-side live photo preview, and inline error styling.
- `students/show.blade.php`: Digital Student ID card preview and complete profile breakdown.
- `students/index.blade.php`: Searchable, filterable student registry directory.

### 4. Storage & File Management
- Profile pictures are securely uploaded to `storage/app/public/students/`.
- Accessible via the public URL generated by `asset('storage/' . $student->profile_picture)`.
- Enabled via `php artisan storage:link`.
